# vice-beautify

[![Open in Hanzo](https://hanzo.app/badges/open-in-hanzo.svg)](https://hanzo.app/dev/open?repo=github.com/zeekay/vice-beautify&ref=master&action=open) [![Edit with Hanzo](https://hanzo.app/badges/edit-with-hanzo.svg)](https://hanzo.app/dev/open?repo=github.com/zeekay/vice-beautify&ref=master&action=edit)

Adds filetype specific `:Beautify` command which beautifies the current buffer.

## Supported filetypes
- JavaScript, JSON
- HTML, XML
- CSS
- C, C++
- Java
- Go
- Python
